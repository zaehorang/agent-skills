# herdr-dispatch

herdr로 일을 위임할 때 **모델 / 추론 강도 / 권한** 세 가지를 의식적으로 고른다.

이 스킬은 herdr CLI 사용법을 담지 않는다. 그건 **herdr 공식 스킬**(`~/.agents/skills/herdr/SKILL.md`)이 정본이고, pane을 쪼개고 에이전트를 띄우는 명령은 거기서 읽는다. 이 스킬은 그 위에 **"무엇을 어떤 설정으로 띄울지"** 만 얹는다.

## 0. 시작 전 — 두 가지 확인

```bash
test "${HERDR_ENV:-}" = 1                              # 아니면 중단
diff -q <(herdr --skill) ~/.agents/skills/herdr/SKILL.md  # 다르면 아래
```

herdr 스킬이 바이너리와 다르면 세션 시작 훅이 안 돌았다는 뜻이다. 사용자에게 알리고 `herdr-setup/sync-skill.sh` 실행을 제안한다. 낡은 herdr 스킬로 진행하면 없는 기능을 쓰거나 있는 기능을 놓친다.

## 1. 에이전트가 필요한지부터 묻는다

**명령을 돌리고 출력을 읽는 게 전부라면 에이전트를 띄우지 않는다.** 테스트·빌드·로그·스크립트는 `pane run` + `pane wait-output` + `pane read`로 끝난다. 에이전트를 띄우면 시작에만 수십 초가 들고, 승인 대기로 멈출 수 있고, 토큰을 쓴다.

에이전트가 필요한 경우는 **판단이 필요할 때** 뿐이다 — 코드를 읽고 의견을 내거나, 고치거나, 무엇을 볼지 스스로 정해야 할 때.

## 2. 일을 역할로 쪼갠다

`references/dispatch-table.md`의 역할표에서 가장 가까운 줄을 고른다. 표에 없으면 가장 비슷한 줄에서 시작한다.

## 3. 세 축을 정하고 근거를 남긴다

역할마다 모델·추론·권한을 정한다. **정한 이유를 한 줄로 남긴다** — 나중에 표를 고칠 때 이 기록이 근거가 된다.

```
reviewer: codex / terra / high / read-only
  → 리뷰는 엣지 케이스를 따라가야 해서 추론을 올림. 고치라고 부른 게 아니라 읽기 전용.
```

권한은 **항상 명시한다.** 안 정하면 pane이 첫 승인 프롬프트에서 `blocked`로 멈추는데, 그 UI는 사용자만 답할 수 있다 (herdr 스킬이 에이전트의 임의 응답을 금지한다). 읽기 전용으로 띄울 수 있는 일이면 읽기 전용으로 띄우는 게 가장 안전하다.

## 4. 띄우고 회수한다

herdr 스킬의 절차를 따르되, `--` 뒤에 3번에서 정한 플래그를 붙인다. 플래그 문법은 `references/dispatch-table.md`에 있다.

기억할 것 둘:

- `--no-focus` — 사용자 포커스를 뺏지 않는다
- `--cwd "$PWD"` — 작업 디렉터리는 상속되지 않는다. 명시해야 한다

## 5. 사용자에게 보고할 때

무엇을 어떤 설정으로 띄웠는지 한 줄로 밝힌다. 사용자가 "그건 과했다 / 부족했다"고 말할 수 있어야 표가 개선된다.

## 표가 틀렸을 때 — 그 자리에서 고친다

모델 이름은 낡는다 (codex 쪽은 은퇴 일정이 붙어 있고, 실제로 은퇴한다). `agent start`가 모델 이름 때문에 실패하면:

```
1. references/dispatch-table.md 맨 위의 "확인일"과 출처 URL을 본다
2. 해당 문서를 확인해 모델명·추론 단계·은퇴일을 고친다
3. 확인일을 오늘로 갱신한다
4. 원래 하려던 일을 계속한다
```

**주기적으로 문서를 감시하지 않는다.** 모델 이름이 틀리면 CLI가 400으로 즉시, 시끄럽게 실패하므로 감시자를 두는 것보다 실패 시점에 고치는 쪽이 정확하고 싸다. 조용히 틀리는 게 아니라는 점이 근거다.

표의 은퇴일이 오늘 날짜에 가깝거나 지났으면, 실패를 기다리지 말고 사용자에게 미리 알린다.

## 이 스킬이 하지 않는 것

- herdr CLI 사용법을 설명하지 않는다 — herdr 공식 스킬을 읽는다
- 사용자가 모델을 지정했으면 다시 고르지 않는다 — 지정된 대로 쓴다
- 승인 대기(`blocked`) 화면에 대신 답하지 않는다 — 사용자에게 가져간다
- 사용자가 만들지 않은 pane·탭·워크스페이스를 닫지 않는다

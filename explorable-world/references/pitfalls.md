# 함정 — 전부 실제로 겪은 것

## 내용

- **같은 객체에 같은 키를 두 번** — `real:"kube-apiserver"` 뒤에 `real:[…]` 를 쓰면 뒤가 앞을 조용히 덮는다. 문법 오류도 없고 화면만 깨진다. 실제 이름은 `real`, 겹 3 목록은 `xr`. `check_world.mjs` 가 자료형으로 잡는다.
- **예시 이름이 공식 용어처럼 보임** — `web` 은 키워드로 읽힌다. `my-shop` 처럼. 문자열 안 `\n` 바로 뒤에 온 이름은 일괄 치환에서 빠지기 쉽다(`\nweb-7d9f6c-…` 가 남았던 사례) — `check_world.mjs` 의 이름 경고로 확인한다.
- **블록끼리 값이 어긋남** — `kubectl get deploy my-shop` 의 출력 `NAME` 이 `web`, 인증서를 만든 경로와 서버 설정이 읽는 경로가 다름. 겹 3 을 다 쓴 뒤 `content-layers.md` 의 일치 점검을 한다.
- **앞 사건의 응답이 남긴 상태를 잊음** — https 사건의 응답이 HSTS 를 남기면 같은 브라우저는 다음 사건에서 http 로 나갈 수 없다. 다음 사건 첫 자막에 시작 상태를 쓴다.
- **범례 색이 다른 용도와 겹침** — 자막 강조를 노랑으로, 코드 명령줄을 파랑으로 쓰면 이름 색 규칙이 무너진다. 엔진은 강조를 흰 굵은 글씨, 명령줄을 흰 글씨로 둔다. `world.css` 에서 노랑·파랑 글자를 새로 쓰지 않는다.
- **원본 자료를 그대로 옮김** — 받은 아키텍처 그림에 틀린 프로토콜(CI/CD → gRPC), 빠진 단계(Step 3)가 있었다. 옮기기 전에 검토한다.

## 그림

- **라벨이 말풍선 글자를 가림 / 말풍선 꼬리가 엉뚱한 곳** — 예전 엔진은 라벨 층이 말풍선 층 위여서 말풍선 글자가 라벨에 묻혔다(지금은 말풍선이 위). 말풍선 꼬리 좌표는 손으로 쓰므로 바로 옆 물체(80번 문 ↔ 443번 문)를 가리키기 쉽다. B8·B9 가 잡는다. 말풍선을 라벨 위에 띄우면 그 라벨은 가려진다.
- **엔진 UI 가 지도를 가림** — 왼쪽 아래 사건 패널(≈268×270px)이 전체 보기에서 왼쪽 집을 가렸다. 열린 더 보기 패널(오른쪽 440px)도 오른쪽 물체를 가린다. 자리는 `world-design.md` 표.
- **라벨이 물체를 가림** — 크레인 지브가 라벨 밑에 가려 "안 그려졌다"고 착각했다. 라벨은 물체 옆·아래에, 그린 뒤 스크린샷으로 확인.
- **선이 바닥 밖으로 삐져나옴** — 부두 배선 길이를 부두 깊이(190)보다 길게(278) 잡았다. 좌표는 영역 크기 안인지 계산한다.
- **전체 보기에서 꼭대기가 잘림** — 화면을 꽉 채우는(`slice`) 무대라 창 비율에 따라 위아래가 잘린다. `home` 의 y·s 를 조정해 높은 건물이 보이게.
- **주인공이 자막에 가림** — 엔진이 사건 중 카메라를 `80/s` 만큼 위로 보정한다. 그래도 가리면 camTo 의 y 를 더 크게(대상이 화면 위로).

## 움직임

- **속성 transform 과 GSAP 이 같은 요소를 만짐** — `setAttribute("transform")` 으로 놓은 요소를 GSAP 으로 움직이면 GSAP 이 처음 읽은 위치를 기억해 엉뚱한 곳으로 튄다. `ISO.mover` 로 바깥(위치)·안쪽 `body`(애니메이션)를 나눈다.
- **배경 움직임 트윈을 reset 에서 죽임** — `gsap.killTweensOf(R.robotPos)` 가 순찰 반복까지 죽였다. reset 은 장면이 만든 것만 되돌리고, 배경 반복은 `pause()/play()` 로만 다룬다.
- **이전 이동이 상태를 덜 되돌림** — 이전·점 이동은 `reset` → 앞 장면들 `progress(1)` 로 상태를 다시 만든다. 장면이 바꾸는 모든 것(클래스, 글자, 투명도, 위치)이 `reset` 에 있어야 한다.
- **장면 함수 밖에서 상태를 바꿈** — 장면 함수가 만들어질 때(타임라인 밖) 바로 상태를 바꾸면 빨리 감기·되돌리기와 어긋난다. 변경은 `tl.set/to/call` 안에서.
- **clearBubbles 의 기준** — 장면 함수가 만들어지는 시점의 말풍선을 지운다. 새 말풍선은 clearBubbles 호출 **뒤에** 만든다.

## 확인

- **백그라운드 탭에서는 애니메이션이 멈춘다** — 브라우저가 보이지 않는 탭의 화면 갱신을 멈추기 때문. 자동화로 확인할 때만 `gsap.ticker.lagSmoothing(0); setInterval(()=>gsap.ticker.tick(),16)` 을 먼저 실행한다. 파일에는 넣지 않는다.
- **멈춘 채로 버튼을 여러 번 누르면 한꺼번에 넘어감** — 위 보정 없이 '다음'을 연달아 누르면 시간이 한 번에 따라잡혀 장면이 몰아서 끝난다. 보정한 뒤 확인한다.
- **고친 파일이 반영되지 않음** — 같은 포트로 다시 열면 브라우저가 예전 `world.js` 를 캐시에서 읽는다. 고친 카메라 값이 그대로여서 "고쳤는데 그대로"로 착각했다. 다시 확인할 때는 서버 포트를 바꾼다.
- **도구 호출이 45초에서 끊김** — 사건 전체를 한 번에 기다리지 말고 `EXPLORER.goBeat(n)` 으로 장면 단위로 나눠 확인한다.

# 작성 중인 글 자동 저장

## Goal
사용자가 글을 쓰다 창을 닫거나 연결이 끊겨도 쓰던 내용을 잃지 않게 한다.

## Triggers
- 사용자가 글 입력란에 무언가를 입력하고 잠깐 손을 멈춘 순간
- 사용자가 글쓰기 화면을 떠나려고 할 때

## Inputs
- 작성 중인 글의 내용 — 사용자가 입력란에 직접 쓴다
- 자동 저장을 켤지 여부 — 사용자가 설정 화면에서 정하고, 정하지 않으면 켜져 있다

## Outputs
- 입력란 아래에 마지막으로 보관된 시각이 보인다
- 보관된 내용은 같은 기기에서 브라우저를 껐다 켜도 남아 있고, 글을 실제로 올리고 나면 지워진다
- 다른 기기에서는 보이지 않는다

## Edge cases
- 입력란이 비어 있으면 아무것도 보관하지 않고, 보관된 시각도 보이지 않는다
- 한글처럼 조합해서 쓰는 글자는 조합이 끝난 뒤에 보관된다
- 보관할 공간이 부족하면 보관을 멈추고, 자동 보관이 되지 않고 있다는 안내가 한 번 보인다
- 같은 글을 두 창에서 동시에 쓰면 나중에 손을 멈춘 창의 내용이 남는다

## Acceptance
- 글을 쓰다 손을 멈추면 입력란 아래에 보관된 시각이 보인다
- 보관된 시각이 보이는 상태에서 브라우저를 껐다 켜고 글쓰기 화면을 열면 쓰던 내용이 그대로 보인다
- 글을 실제로 올린 뒤 글쓰기 화면을 다시 열면 입력란이 비어 있다
- 자동 저장을 끈 상태에서 글을 쓰고 손을 멈추면 보관된 시각이 보이지 않는다
- 입력란을 모두 지운 뒤 손을 멈추면 보관된 시각이 사라진다

## 열린 질문
- 손을 멈춘 뒤 얼마나 지나서 보관해야 하는가. 현재 동작에는 근거가 남아 있지 않다.
- 다른 기기에서도 이어 쓰게 하는 것이 원래 의도였는가.
